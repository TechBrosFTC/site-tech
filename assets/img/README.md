# Imagens do site

Substitua os placeholders por imagens oficiais da equipe quando estiverem disponíveis.

- `equipe-hero.jpg`: foto principal da equipe e técnicos, idealmente 1920x1080.
- `foto-equipe.svg`: placeholder da página Quem Somos. Pode ser trocado por `foto-equipe.jpg` e o HTML atualizado.
- `parceiros/`: logos dos patrocinadores. Use arquivos WebP, SVG ou PNG otimizados.
- `temporadas/`: fotos do robô, capa da temporada e imagens de galeria.

Evite imagens, personagens, logos ou elementos oficiais protegidos de franquias de jogos. A identidade visual deste site usa apenas elementos genéricos de aventura/plataforma.
